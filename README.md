# 吃什么 (Fork-Cast)

> 不做选择题，输入大白话直接拍板 · 零标签随性就餐决策机

[**现在体验「吃什么」**](https://eat.march7th.codes/)

今天吃什么？这大概是现代人每天最耗费心智的问题。

传统的就餐工具要么逼你给几十道菜打标签（辣度、菜系、价格区间），要么在庞大的外卖软件里滑动半小时越看越纠结，要么用大语言模型跟你车轱辘对话三分钟还给不出准话。

**「吃什么」** 彻底摒弃这些累赘。它接入专门用于直觉决策的 **System 1 概率决策模型**（全面支持 TypeSafe Jev 与 Liquid AI D1），无需分类打标，你只需随手敲下一句大白话，它便在毫秒之间为你完成确定性拍板。

---

## 为什么选择「吃什么」

- **大白话直出，零标签负担**  
  不用维护繁琐的菜系属性。输入你最真实的当下状态与情绪——*“淋雨了想喝口滚烫的汤”*、*“胃胀求清淡”*、*“发薪日想吃肉”*——系统即刻理解并给出抉择。
- **直觉级毫秒拍板，拒绝车轱辘废话**  
  不同于传统聊天机器人的漫长文本生成与玄学 Prompt，「吃什么」直接测算数学概率与置信度，不扯闲篇、不编故事、瞬间定音。
- **吃过就不想再吃？自动防腻避让**  
  内置智能防腻回溯机制。近两天刚吃过的菜品会自动降权避让，常吃常新，避免连续几天撞菜单。
- **尊重隐私，纯前端本地存储**  
  你的个人菜品清单、就餐历史足迹、设置偏好全都在你的浏览器本地保存，不搞云端用户画像，不留多余痕迹。

## 四种自适应裁决形态

面对不同的心情和诉求，「吃什么」会给出四种截然不同的裁决结果：

| 裁决形态 | 触发场景 | 体验特色 |
| :--- | :--- | :--- |
| 🎯 **拍板落定**<br>*(Decisive Pick)* | 某一候选优势显著、置信度高 | **一锤定音**：直接给出首选推荐，附带置信度与备选建议。满意就开吃，不满意可一键排除并重新决策。 |
| ⚔️ **势均力敌**<br>*(Dilemma Duel)* | 两道候选在心头难分伯仲 | **双雄转盘对决**：既然都不错，就让转盘做最后一击。单次决胜，禁止无限重抽，终结反复纠结。 |
| 🚫 **神仙难救**<br>*(Impasse)* | 诉求自相矛盾或候选池被清空 | **理性劝退**：识别出“既要滚烫又要冰爽”等不可能条件，或当你把常吃菜都临时划掉时，直言相告，提醒你放平心态。 |
| 🎲 **随缘盲盒**<br>*(Blind Box)* | 输入“随便”、“都行”彻底摆烂 | **纯粹机械摇号**：毫无偏好时直接进入均等概率盲盒，随缘抽取，且不污染你的真实用餐防腻历史。 |

## 打造专属于你的常吃清单

每个人的食谱都不一样，在「吃什么」里你完全掌控自己的选择池：

- **36 项精选上限**：候选池上限 36 道常吃菜品或常去餐馆。这既覆盖了绝大多数人的日常轮换周期，又避免了选项过多带来的决策瘫痪。
- **自由增删编辑**：点击侧边设置抽屉，随时增补心头好或移除吃腻的选项；误操作时支持一键恢复默认推荐。
- **自定义防腻回溯窗口**：
  - **24 小时（1 天）**：适合菜单少但不在意短期复吃的生活节奏。
  - **48 小时（2 天 · 默认）**：最舒适的日常间隔，两天内吃过的品类自动降权避让。
  - **72 小时（3 天）** / **1 周**：拉长轮换周期，逼自己探索更多可能。
  - *饱和自愈*：若候选清单中所有菜品在周期内都吃过，系统会自动平滑降权惩罚，绝不让你陷入无饭可吃的死局。

## 免费额度与隐私保障

- **每日 10 次免费额度**  
  每个设备每日均享 10 次免费模型决策额度。每天北京时间午夜 **00:00 自动重置**，满足绝大部分日常三餐决策需求。
- **自备密钥模式 (BYOK)**  
  如果你需要更高频的调用，可在设置中填入个人的 TypeSafe 或 Liquid AI API Key：
  - 享受**无限次私有决策**，不再受每日公共配额限制；
  - 密钥严格加密保存在浏览器本地，仅在决策瞬间透传给模型网关，**绝不在服务器落盘**；
  - 密钥失效时明确提示，绝不悄悄扣减公共额度。
- **离线模拟模式 (Mock)**  
  在未联网或无可用 Key 的离线环境下，内置的高保真决策模拟引擎依然能够顺畅运作，完整体验拍板、决斗、防腻等全套玩法。
